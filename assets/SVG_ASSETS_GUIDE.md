## 🎨 How to Use in Canva

### Importing SVGs

1. **Open Canva** and create your design
2. Click **"Uploads"** in the left sidebar
3. Click **"Upload files"**
4. Select the SVG files you want to use
5. Drag and drop onto your canvas

### Working with Logos

**For Social Media Posts**:
- Use `workshop-anvil-simple.svg` for profile pictures
- Use `workshop-logo-horizontal.svg` for cover images
- Scale to fit, maintain aspect ratio

**For Business Cards**:
- Use `workshop-anvil-icon.svg` on front
- Use `workshop-wordmark.svg` on back
- Recommended size: 300-400px width

**For Presentations**:
- Use `workshop-logo-horizontal.svg` on title slide
- Use `workshop-anvil-simple.svg` in slide corners
- Keep consistent sizing throughout

### Working with Icons

**Icon Sizes in Canva**:
- Small: 24-32px (UI elements)
- Medium: 48-64px (feature highlights)
- Large: 96-128px (hero sections)

**Changing Icon Colors**:
1. Select the icon after importing
2. Click on the color area
3. Choose your color (use brand colors!)
4. Brand colors: #D4AF37 (brass), #4A90E2 (blue), #F8F9FA (white)

**Icon Usage Examples**:
- `hammer.svg` - Services, building, construction themes
- `blueprint.svg` - Planning, strategy, technical content
- `code.svg` - Development, programming content
- `gear.svg` - Settings, engineering, process
- `check.svg` - Success states, completed items
- `arrow-right.svg` - Call-to-action, navigation

### Working with Patterns

**Blueprint Grid Background**:
1. Import `blueprint-grid.svg`
2. Resize to cover full canvas
3. Adjust transparency to 10-30%
4. Place behind other content
5. Use for: Technical presentations, case studies, documentation

**Geometric Pattern Background**:
1. Import `geometric-pattern.svg`
2. Resize and tile if needed
3. Set transparency to 5-15%
4. Use for: Hero sections, feature backgrounds

### Working with Elements

**Divider Lines**:
- `divider-brass.svg` - Place between sections
- Resize width to fit your layout (maintain 2-4px height)
- Use to separate content blocks

**Corner Brackets**:
- `corner-bracket.svg` - Add to photo corners
- Rotate 90°/180°/270° for other corners
- Creates blueprint/technical feel
- Great for case study images

**Badge/Seal**:
- `badge.svg` - Add text or icons in center
- Use for: Certifications, special offers, labels
- Resize: 80-150px typically

**Button Template**:
- `button-brass.svg` - Ready-made button background
- Add text on top (use IBM Plex Mono font)
- Text color: #2B2D2F (Foundry Charcoal)
- Resize width as needed, maintain height ratio

## ✅ Design Tips

### DO:
✓ Maintain aspect ratios when resizing
✓ Use brand colors consistently
✓ Combine logos with brand colors only
✓ Keep adequate white space around logos
✓ Use patterns at low opacity (5-15%)
✓ Group related icons for visual consistency
✓ Use grid patterns for technical content
✓ Layer elements thoughtfully

### DON'T:
✗ Stretch or distort logos
✗ Change logo colors to off-brand colors
✗ Place logo on busy backgrounds
✗ Use patterns at high opacity
✗ Mix too many decorative elements
✗ Ignore the brand color palette
✗ Overcrowd designs with icons
✗ Use logos smaller than 80px wide

## 🔧 Troubleshooting

### SVG Not Importing?
- Ensure file extension is `.svg`
- Try re-downloading the file
- Check Canva supports SVG (Pro feature in some cases)
- Convert to PNG if needed (but SVG is better for scaling)

### Colors Look Different?
- Canva may interpret colors slightly differently
- Manually set colors using hex codes provided
- Check if transparency is affecting appearance
- Preview in multiple export formats

### Logo Looks Blurry?
- You may have rasterized it - undo and keep as vector
- Increase size before placing in design
- SVGs should scale perfectly - if blurry, it's likely been converted to raster

### Can't Edit Icon Colors?
- Some SVGs may be grouped - try ungrouping
- Click through layers to find the color element
- If imported as image, it won't be editable - reimport as SVG

## 🎓 Advanced Techniques

### Creating Depth with Layers
1. Background pattern (5% opacity)
2. Large decorative elements (10-15% opacity)
3. Main content (100% opacity)
4. Foreground accents (brass highlights)

### Using Multiple Patterns
- Combine blueprint grid + geometric pattern
- Set different opacities (grid at 10%, geometric at 5%)
- Offset patterns slightly for depth

### Icon Arrangements
- **Rule of 3**: Use 3 icons for features/benefits
- **Symmetry**: Arrange in equal spacing
- **Hierarchy**: Make primary icon larger
- **Color**: Alternate brass and blue for variety

### Custom Badge Creation
1. Import `badge.svg`
2. Add center icon (e.g., `check.svg` at 30px)
3. Add text around edge if needed
4. Duplicate and resize for consistency

## 📤 Exporting from Canva

### For Web Use
- **Format**: PNG or SVG
- **Quality**: Standard (screens don't need ultra-high)
- **Transparency**: Check if you need transparent background
- **Size**: Usually 1-2x the display size

### For Print Use
- **Format**: PDF (best) or PNG (high quality)
- **Quality**: Highest
- **DPI**: 300 DPI minimum for print
- **Bleed**: Add 0.125" bleed if trimming

### For Social Media
- **Format**: PNG or JPG
- **Quality**: Standard to High
- **Size**: Platform-specific sizes (see Recommended Templates)
- **Compression**: Let platform handle it
