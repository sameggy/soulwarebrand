## 🚀 How to Use These Files

### Opening SVG Logos:

**In Your Web Browser:**
1. Right-click any `.svg` file
2. Open with: Chrome, Firefox, Safari, or Edge
3. View the scalable vector logo
4. Right-click → "Save Image As" to export as PNG if needed

**In Design Software:**
- **Adobe Illustrator:** File → Open → Select SVG
  - Fully editable vectors
  - Can change colors, adjust spacing
  - Export to any format (.ai, .eps, .pdf, .png, .jpg)

- **Figma/Sketch:** Drag and drop SVG file directly into canvas
  - Auto-converts to editable vectors

- **Inkscape (Free):** File → Open → Select SVG
  - Free alternative to Illustrator
  - Full vector editing capability

**Converting to Other Formats:**
- Use design software above to export to .png, .jpg, .pdf
- Or use online converters: CloudConvert, SVG to PNG converter

### Opening HTML Website Mockup:

**To View:**
1. Double-click `website_mockup.html`
2. Opens in your default web browser
3. Scroll through to see full homepage design
4. Resize browser window to see responsive design

**To Edit:**
1. Open in any code editor (VS Code, Sublime Text, Atom, even Notepad)
2. All styles are in the `<style>` section at the top
3. Content is in the `<body>` section
4. Save changes and refresh browser to see updates

**To Screenshot for Mockups:**
1. Open in browser
2. Use browser screenshot tools or:
   - Mac: Cmd + Shift + 4
   - Windows: Windows + Shift + S
   - Or use full-page screenshot extensions

**To Send to Developer:**
- Send the entire HTML file
- They can extract CSS and HTML structure
- All brand colors are in CSS variables at top

## 🔧 Customizing the Logos

### Changing Colors in SVG:

1. Open SVG file in code editor or design software
2. Find color codes (e.g., `#C4A27A`)
3. Replace with your chosen color
4. Save file

**Example:** To make logo all one color:
- Replace all instances of `#C4A27A` and `#00D9FF` with `#2C2520` (all dark)

### Removing Background:

The background rectangles are just for viewing. To remove:
1. Open SVG in code editor
2. Find line: `<rect width="..." height="..." fill="..."/>`
3. Delete that line
4. Save - now you have transparent background

## 💡 Tips for Best Results

**SVG Logos:**
- ✅ Use SVG whenever possible (scales perfectly)
- ✅ Export to PNG only when SVG not supported (email, some social media)
- ✅ Export PNG at 2x-3x size for retina displays
- ✅ Keep originals editable - never flatten your only copy

**Website Mockup:**
- ✅ Open in modern browser (Chrome, Firefox, Safari, Edge)
- ✅ View on mobile and desktop to see responsive design
- ✅ Use as reference for developer, not production code
- ✅ Extract color codes and typography specs for design system

**Colors:**
- ✅ Always maintain 70% warm / 25% cool / 5% energy ratio
- ✅ Use exact hex codes provided (don't eyeball/approximate)
- ✅ Test color contrast for accessibility (especially text on backgrounds)

## 🆘 Troubleshooting

**"SVG won't open in browser"**
- Make sure file extension is `.svg` not `.svg.txt`
- Try different browser
- Right-click → Open With → Browser name

**"Logo looks pixelated"**
- You're viewing a raster export (PNG/JPG)
- Open the original SVG file
- SVG is vector = infinite quality at any size

**"Colors look different on my screen"**
- Screen calibration varies
- Use hex codes (#C4A27A) for exact colors
- Professional print: Use CMYK values from brand guidelines

**"Website mockup broken"**
- Make sure it's the complete HTML file
- Needs internet connection for fonts
- Try different browser
