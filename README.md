## 📐 Typography at a Glance

- **Headings**: IBM Plex Mono (300, 400, 500, 600)
- **Body**: Inter (400, 500, 600)
- **Special**: Playfair Display (400, 600, 700) - use sparingly

**Scale**: 72px / 48px / 36px / 24px / 20px / 18px / 16px / 14px / 12px

---

## ✨ Key Design Principles

1. **8-Point Grid**: All spacing in multiples of 8px
2. **Craft Meets Code**: Blend artisan quality with technical precision
3. **Minimal Corners**: Use 2-4px radius for most elements
4. **Subtle Textures**: 5-15% opacity for depth without distraction
5. **Purposeful Animation**: 200-400ms, mechanical easing
6. **Tool-Inspired Icons**: 2px stroke, geometric, outlined
7. **Active Voice**: Confident, specific, never vague

## 🎯 Brand Voice Snapshot

### DO Say
✓ Build, craft, forge, assemble, engineer
✓ Precise, meticulous, intentional, deliberate
✓ Foundation, structure, blueprint, framework
✓ "We build X with Y"
✓ Specific, measurable details

### DON'T Say
✗ Disruptive, revolutionary, game-changing
✗ Amazing, incredible, world-class
✗ Leverage, synergy, paradigm
✗ "Very," "really," "quite"
✗ Passive voice constructions
